# Swiggy Sales Analysis Dashboard

## Project Overview

The **Swiggy Sales Analysis Dashboard** is an Excel-based data analysis project focused on analyzing food sales, customer ratings, restaurant performance, and order trends across different cities and states in India.

The objective of this project is to transform raw food sales data into meaningful business insights using Microsoft Excel. The project includes data analysis, KPI calculations, Pivot Tables, charts, and an interactive dashboard to understand sales performance and customer behavior.

## Dataset Overview

The dataset contains **197,430 records** with information about food items, restaurants, locations, sales prices, customer ratings, and order dates.

**Key Dataset Columns:**
- State
- City
- Order Date
- Day
- Quarter
- Week
- Restaurant Name
- Location
- Category
- Dish Name
- Food Type (Veg / Non-Veg)
- Price (INR)
- Rating
- Rating Count

## Project Objectives

- Analyze overall food sales performance.
- Understand monthly and daily sales trends.
- Compare Veg and Non-Veg sales contributions.
- Identify top-performing cities and states.
- Analyze customer ratings and review counts.
- Evaluate quarterly business performance.
- Identify weekly sales patterns and peak periods.
- Present business insights through an Excel dashboard.

## Key Performance Indicators (KPIs)

The dashboard focuses on the following five KPIs:

1. **Total Sales (₹):** Overall revenue generated from food items.
2. **Average Rating:** Average customer rating across restaurants and food items.
3. **Average Order Value (₹):** Average sales value per recorded item/order entry.
4. **Ratings Count:** Total number of customer reviews.
5. **Total Orders:** Total number of food records analyzed.

## Dashboard Charts & Analysis

The dashboard includes the following visualizations:

1. **Monthly Sales Trend** – Analyzes how total sales fluctuate month by month.

2. **Daily Sales Trend** – Highlights sales and order variations across different days of the week.

3. **Total Sales by Food Type (Veg vs Non-Veg)** – Compares revenue contributions from vegetarian and non-vegetarian food items.

4. **Total Sales by State (Map Visualization)** – Displays state-wise sales distribution across India.

5. **Quarterly Performance Summary** – Compares sales, average ratings, and order records across different quarters.

6. **Top 5 Cities by Sales** – Identifies the five highest-performing cities based on total sales.

7. **Weekly Trend Analysis** – Monitors weekly sales fluctuations to identify peak periods and sales consistency.
